## Stage 6 scientific boundary

The current Stage-6 foundation is not automatically classified as complete semantic memory, hierarchical predictive coding or a generative world model. The scientific roadmap now requires mechanism-specific tests for semanticization/replay, neural prediction-error processing, multi-step action-conditioned dynamics, coupled checkpoint identity and independent replication.

## Integrity boundary

The repository can enforce attribution/provenance rules and detect known risk patterns, but it does not certify plagiarism-freedom. External source/similarity review remains a pre-submission requirement.
