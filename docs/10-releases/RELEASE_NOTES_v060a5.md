## Engineering state

The exact release source freeze must pass Python 3.11/3.12/3.13, typing, linting, browser E2E, build, Docker and the scientific/publication/DATA integrity gates.

## Scientific state

This release is **not a declaration that the scientific programme is complete**. Edition 1.8 remains a current WIP. Some scoped claims have human-reviewed project EVID; other experiments remain DATA-only or pending review. Independent external replication is not complete.

A GitHub release or DOI provides a stable, citable artifact. It does **not** by itself create peer review, scientific truth, novelty, biological equivalence or independent replication.

## AI-use disclosure

AI systems materially assisted with research leads, critical counterarguments, structure, code generation, tests, debugging and manuscript drafting. MHRN treats this governed human–AI workflow itself as a methodological research object.

AI systems are not listed as scientific authors and do not receive evidence authority. Thomas Heisig remains responsible for acceptance, rejection, human approval and publication decisions.
