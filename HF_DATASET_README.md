# MHRN Research Data

This dataset repository is an automatically generated public mirror of the `research/` tree from the canonical MHRN GitHub repository.

Canonical source: https://github.com/Thomas-Heisig/MHRN

The mirror exists for discovery and reproducibility. It does **not** promote experiment DATA to accepted EVID. Historical experiment artefacts retain their original status, provenance and review boundaries.

For citable experiment-specific research objects, use a dedicated DOI-bearing archive when one is explicitly published. Do not treat this rolling mirror as a substitute for immutable release or dataset DOIs.
