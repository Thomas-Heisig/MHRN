# Recursive Epistemics stop rule

Each meta-analysis is bounded by a frozen **claim episode** corpus.

```text
frozen claim episode
-> one declared meta-analysis
-> meta-DATA / analysis
-> human review
-> bounded meta-claim
-> new unresolved issue becomes a new RQ/protocol
```

The same episode may be revisited only under a separately versioned question/protocol. A transformed analysis cannot support itself, and no meta-level conclusion automatically changes object-level EVID.
