# Meta-research recursion stop rule

**Status:** normative research-process contract; not DATA and not EVID.

A meta-study operates on a finite, frozen **claim episode corpus**. The corpus boundary,
adjudication reference, analysis code and eligible provenance records are frozen before
confirmatory responses are inspected.

The allowed chain is:

`claim episode -> defined meta-analysis -> meta-DATA -> human review -> bounded meta-claim`.

A new uncertainty, contradiction, tool version, model family, reviewer population or
governance hypothesis creates a **new RQ/protocol**. It does not reopen the same episode
indefinitely and does not turn a methodological witness into proof of the rule motivated
by that witness.

## Anti-circularity rules

- A case that motivated a governance control cannot by itself validate that control.
- AI output cannot serve as an independent external source for a claim derived from the
  same AI lineage.
- Human Review cannot be counted as independent replication.
- A generated report cannot be promoted to raw DATA.
- A meta-study cannot alter the frozen adjudication reference after response inspection.
- No automatic EVID promotion is permitted.

## Termination criterion

The analysis terminates when the preregistered outcomes and failure rules have been
evaluated against the frozen corpus. Residual questions are registered separately.
