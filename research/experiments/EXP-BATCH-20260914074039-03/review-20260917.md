## `stopped_on_quiescence`

All 12 runs report `stopped_on_quiescence: false`. For `deterministic_replica_v1`, this is expected operational telemetry rather than a failed endpoint.

`run_ping_v2` uses a fixed observation window by constructing the probe with `min_ticks == max_ticks == ticks`. `NetworkImpulseProbe` sets `stopped_on_quiescence=true` only when execution terminates before `max_ticks` because the runtime reports quiescence. Consequently, a fixed-window run that completes all requested ticks reports `false` even if the runtime reports quiescence on the final allowed tick. The field therefore means **"terminated early because of quiescence"**, not **"the network never became quiescent"**.

This metric must not be interpreted as a primary success/failure criterion for `H-SNN-003-A` unless a future preregistration explicitly defines an early-stop/quiescence endpoint.
